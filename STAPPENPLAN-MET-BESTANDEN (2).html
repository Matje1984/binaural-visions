STAP 1 — Zet app online (10 min) — Gratis hosting via GSM

Via Chrome op je GSM:

  1. Chrome → github.com/new → log in → repo naam binaural-visions → Public → Create repository
  2. In nieuwe repo → Add file → Upload files → kies uit Downloads: binaural-app-voor-mezelf-en-store.html + manifest.json + icon_512.png + icon_192.png
  3. Maak ook index.html met inhoud: <meta http-equiv="refresh" content="0; url=binaural-app-voor-mezelf-en-store.html"> → upload ook
  4. Commit → Ga naar Settings → Pages → Source: main branch / root → Save
  5. Wacht 2 min → je URL: https://JOUWUSERNAME.github.io/binaural-visions/binaural-app-voor-mezelf-en-store.html
  6. Test: open URL in nieuw tabblad → app moet werken + FAQ + à la carte shop zichtbaar

Geen GitHub? Alternatief: Chrome → app.netlify.com → drag & drop je bestanden → krijg direct URL (nog sneller op GSM)

STAP 2 — Maak AAB bestand (5 min) — Geen PC nodig!

Via Chrome op je GSM via PWABuilder:

  1. Chrome → pwabuilder.com → plak je GitHub URL uit stap 1
  2. Tik Start → wacht scan → tik Build My PWA → kies Android
  3. Vul in:
    • Package ID: com.mfgregoireen.zoon.binauralvisions (exact onthouden!)
    • App name: Binaural Visions
    • Theme: #fcd34d, Background: #07070f
    • Signing: YES (laat PWABuilder signen)
    • Enable Play Billing: YES (voor €1 modules)
  4. Tik Build → 1-2 min wachten → Download AAB → opgeslagen in Downloads als app-release.aab

Bewaar AAB goed! Dit is je Android app bestand voor Play Store.
